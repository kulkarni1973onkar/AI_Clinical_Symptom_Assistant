Medical Note Assistant

Vercel deployment ready

This repository is configured for Vercel static hosting. The app is a Streamlit-based Python frontend that depends on a local Ollama model server and cannot run directly as a Vercel serverless function.

To preview the full assistant, run it locally from the repository root: 

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m spacy download en_core_web_sm
streamlit run app.py
Note: Vercel currently hosts only this landing page. The actual Streamlit + Ollama application requires a local runtime.
